================================================================================
                         ROOT CAUSE EXPLANATION
================================================================================

Why it was hanging:

  1. database.py was imported by main.py
  2. Module-level line: engine = create_engine(DATABASE_URL)
  3. This tried to connect to PostgreSQL immediately
  4. PostgreSQL not installed, so it waited indefinitely
  5. Main app never reached "startup complete"

How it's fixed:

  1. engine = None (no connection on import)
  2. get_engine() creates connection only when needed
  3. SQLite has 5 second timeout
  4. PostgreSQL has 5 second timeout
  5. If database fails, app continues with warning

Result:

  ✅ Server starts immediately
  ✅ No external dependencies
  ✅ Graceful error handling
  ✅ Works with SQLite or PostgreSQL
